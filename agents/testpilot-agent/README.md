# TestPilot Agent

Agent for test planning, execution, and failure analysis.

MCP server:

```text
test-mcp
```

Tools:

- `test_detect_project_type`
- `test_discover_test_commands`
- `test_run_unit_tests`
- `test_run_integration_tests`
- `test_run_specific_test`
- `test_analyze_failures`
- `test_collect_test_reports`
- `test_generate_test_summary`
- `test_current_change_report`
