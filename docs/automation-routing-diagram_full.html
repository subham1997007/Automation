Automation Folder Setup + MCP Tool Routing

Controlled​ Agentic Development  with  AI Tool Routing

A team copies the Automation folder, enables one profile, restarts the IDE, and then asks normally. Copilot/Windsurf can use only the MCP tools exposed by that selected profile, with memory, guardrails, and approval gates.

1

Copy Automation Folder

Place the portable Automation folder inside any project repository.

2

Add Local Config

Keep project credentials and tool settings in the private local env file.

3

Run Profile Command

Choose one profile. Setup installs dependencies and writes IDE MCP config.

4

Restart IDE

Copilot, Windsurf, VS Code, or JetBrains reloads the selected MCP server.

5

User Request

Ask normally: update story, prepare MR, run tests, review, or implement.

6

Copilot / Windsurf

The AI host selects from the active profile's exposed MCP tools.

7

MCP Server + Tools

Runs the selected tool with memory, safety checks, and approval gates.
