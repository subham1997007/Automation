Core Benefits

🔒

Always Controlled

Every agent stops before code changes or MR creation. Important decisions always stay with the human. No silent writes, no surprise commits.

⚡

Faster Story Readiness

Jira Agent reads the story, identifies gaps, suggests ACs, regulatory justification, and subtask plan — ready for PO review in seconds.

🎯

Focused Code Changes

Dev Flow Agent returns a scoped implementation contract so the coding agent makes small, pattern-following changes without unrelated refactoring.

🧪

Built-In Quality Evidence

Test Agent and Review Agent collect test scope, failure analysis, diff review, risk signals, and AC coverage before the MR is even drafted.

🌿

Safer Merge Requests

GitLab Agent checks branch safety, uses the project MR template, and creates the MR only after human approval with full evidence attached.

📁

Portable Automation

The Automation folder travels with the project. Copy it, run one command, restart the IDE — agents are live in any repo instantly.

For Developers

Dev Flow · GitLab Flow · Test Flow · Review Flow

Dev Flow Agent
⚙️

End-to-End Story Implementation

One request does it all: reads Jira, analyses codebase, validates ACs, proposes changes, runs tests, reviews, and drafts MR — each step gated by your approval.

GitLab Flow Agent
🌿

Safe Branch & MR Management

Correct branch naming, governed MR description with AC coverage and test evidence. Blocks unsafe actions like force-push to protected branches.

Test Flow Agent
🧪

Auto-detect & Run Tests

Detects Maven/npm/etc., discovers test commands, executes suites, summarises pass/fail, and attaches evidence to the MR automatically.

Review Flow Agent
🔍

Pre-MR Code Review

Reviews changed files against ACs, flags missing tests, checks Checkstyle/PMD compliance, and produces a readiness report before the MR is raised.
